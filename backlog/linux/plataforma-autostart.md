# Início automático

**Plataforma:** linux · **Estado:** falta · **Esforço:** P

## O que é

Não se aplica como no Windows: sem residente, não há o que iniciar.

## Como fazer

O item existe para registrar a diferença: como os atalhos vivem no
`hyprland.conf`, não há processo em segundo plano. O que se documenta é
como acrescentar os binds.
