# Reconhecimento de texto

**Plataforma:** macos · **Estado:** falta · **Esforço:** M

## O que é

Reconhecer texto na captura.

## Como fazer

**Vision** (`VNRecognizeTextRequest`) — nativo, bom, sem instalar nada. É o
equivalente direto do `Windows.Media.Ocr`, e o motivo de o macOS conseguir
paridade plena onde o Linux não consegue.
