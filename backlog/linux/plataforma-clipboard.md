# Área de transferência

**Plataforma:** linux · **Estado:** falta · **Esforço:** M

## O que é

Copiar imagem e texto.

## Como fazer

`wl_data_device` pelo protocolo, ou delegar a `wl-copy` (wl-clipboard). O
segundo é muito mais simples e é o que a maioria das ferramentas do
ecossistema faz; o custo é uma dependência externa de runtime.
