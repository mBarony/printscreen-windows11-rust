# Abrir imagem de arquivo

**Plataforma:** linux · **Estado:** falta · **Esforço:** M

## O que é

Decodificar JPG/PNG/BMP para abrir no editor, equivalente ao GDI+.

## Como fazer

Não há decodificador de sistema. O projeto já tem codificador JPEG próprio;
o decodificador é o caminho inverso. PNG depende de `nucleo/formato-png`.
