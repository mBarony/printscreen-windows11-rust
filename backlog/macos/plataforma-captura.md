# Captura de tela

**Plataforma:** macos · **Estado:** falta · **Esforço:** G

## O que é

Congelar o conteúdo dos monitores.

## Como fazer

ScreenCaptureKit, a API atual (a antiga `CGDisplayCreateImage` está
depreciada). Exige permissão de **Gravação de Tela**, concedida uma vez pelo
usuário nas Preferências do Sistema.
